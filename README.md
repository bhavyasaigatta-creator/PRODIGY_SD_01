# PRODIGY_SD_01

## Software Development Internship - Prodigy InfoTech

### Task 1: Temperature Converter

### Description
This project is a temperature conversion program that converts temperature values between Celsius, Fahrenheit, and Kelvin scales. The user inputs a temperature value and selects the unit, and the program converts it into other units.

### Features
- Converts Celsius to Fahrenheit and Kelvin
- Converts Fahrenheit to Celsius and Kelvin
- Converts Kelvin to Celsius and Fahrenheit
- Easy user input

### Technologies Used
- Python

### How to Run
1. Open the file in any Python IDE or terminal
2. Run the program
3. Enter temperature value and unit
4. View the converted results

### Sample Output

Enter temperature: 25  
Select unit (C/F/K): C  

Converted Temperatures:  
Fahrenheit: 77.0  
Kelvin: 298.15
